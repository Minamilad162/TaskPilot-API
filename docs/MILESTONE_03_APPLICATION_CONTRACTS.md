# Milestone 03 - Application Contracts

## Branch

`feature/application-contracts`

## Scope

This milestone adds the application-level contracts that define how the API, infrastructure, and domain layers will communicate.

## Added

- Authentication request and response DTOs
- Project request, response, and details DTOs
- Task request and response DTOs
- Application service interfaces
- Current user and JWT abstractions
- Application database context abstraction
- Shared API response wrapper
- Application-level exception types

## Notes

No persistence or controller implementation is added in this milestone. The goal is to define stable contracts before adding infrastructure and use-case implementation.
